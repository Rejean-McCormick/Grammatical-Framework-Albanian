# Albanian RGL overview

The final product and maturity target are defined by `docs/canonical/03_FINAL_PRODUCT_AND_DEFINITION_OF_DONE.md`.

The project targets Standard Albanian. Structural green status and scenario execution are not linguistic certification. The C10 certification runtime under `validation/certification/` records execution evidence, review evidence, gold promotion, coverage, parity and release gates without modifying grammar-owned defects.
