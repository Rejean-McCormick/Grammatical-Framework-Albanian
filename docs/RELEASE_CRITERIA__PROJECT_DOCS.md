# Release criteria

Canonical criteria are defined by:

- `docs/canonical/17_TESTING_CERTIFICATION_AND_RELEASE_LEVELS.md`
- `docs/canonical/22_RELEASE_GATES.md`
- `docs/canonical/28_DEVELOPMENT_STATE_MAP.md`

The current machine-derived release packet is `validation/certification/release/CURRENT_RELEASE_PACKET.md`.

A release claim must separately report structural status, linguistic certification status, gold regression status, coverage status, parity status and visible debt.
