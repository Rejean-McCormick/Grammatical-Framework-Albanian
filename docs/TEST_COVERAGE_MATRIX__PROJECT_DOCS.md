# Test coverage matrix

The canonical testing model is `docs/canonical/17_TESTING_CERTIFICATION_AND_RELEASE_LEVELS.md`.

Machine-readable C10 coverage is generated under `validation/certification/coverage/`:

- phenomenon coverage;
- category coverage;
- morphology-cell coverage;
- abstract-function coverage;
- paradigm registry;
- coverage summary.

Executed-only evidence is distinct from reviewed and gold-protected evidence.
