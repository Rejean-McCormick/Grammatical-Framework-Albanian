# Build sequence and handoff contract

## Phase C9.0 — lock, inventory, traceability

- close or explicitly block exact RGL identity (`C9-DEC-001`);
- freeze function matrix and public API matrix;
- establish evidence/test/decision registers;
- create focused scenario namespaces;
- no feature change before row IDs and owners are known.

**Exit:** reproducible source identities + matrices + test entrypoints.

## Phase C9.1 — Structural certification

Work by semantic family: government → pronouns/interrogatives → determiners/quantifiers → coordination/subordination → adverbials → modals/structural verbs.

**Exit:** all C9-STR rows have stable coverage disposition; high-risk families have reviewed scenarios.

## Phase C9.2 — Extend common surface

Review inherited defaults first, then locally owned families. Repair core owners when advanced failures expose a core defect.

**Exit:** no unexplained C9-EXT partial/missing rows; advanced scenarios green; retained defaults promoted.

## Phase C9.3 — Extra compatibility

Keep common Extra compatible and deduplicated relative to Extend. Evaluate English-only additions individually.

**Exit:** Extra is compatibility surface, not parallel grammar.

## Phase C9.4 — Public API ergonomics + compatibility

Audit Syntax/Constructors/Combinators/Try/Symbolic and decide Browse. Generate export/collision census where GF tooling permits.

**Exit:** facade-only grammars compile; API compatibility contract passes.

## Phase C9.5 — Documentation/Symbol/Markup

Synchronize with final category contracts and add rendering/table-cell tests.

**Exit:** no stale representation assumptions.

## Phase C9.6 — linguistic certification + release candidate

- full Wordbench;
- review output/parse changes;
- promote accepted advanced cases to gold;
- close release-blocking decisions;
- complete closure checklist;
- publish final status with known limitations.

## Handoff contract

Use `25_PATCH_RECORD_TEMPLATE.md` for every delivery. A handoff without `NOT YET CERTIFIED`, compatibility impact, and exact row/evidence/test IDs is incomplete.
