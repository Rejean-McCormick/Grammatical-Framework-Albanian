# Domaine nominal complet

## Scope
`NounSqi`, `AdjectiveSqi`, `NumeralSqi`, `NamesSqi`, `StructuralSqiNominal`, ressources nominales partagées.

## Décisions globales

- Gen grammatical distinct de Dat, syncrétisme explicite au boundary morphologique.
- genre nominal dépend du nombre.
- accord pluriel conserve le genre.
- *nyje* centralisée et unique.
- adjectifs articulés/non articulés deviennent une classe typée, pas un Bool opaque à long terme.
- morphologie adjectivale = genre × nombre ; *nyje* gère cas/définitude/context.
- pas de `Neut` productif dans le core sans preuve Standard de comportement productif.
- pas de `NumeralGov` tant que des minimal pairs albanais ne justifient pas la distinction.

## Questions qui restent réellement ouvertes

- inventaire moderne des reliques neutres ;
- ordre et restrictions des possessifs prénominalisés ;
- comparatif/superlatif et interaction exacte avec *nyje* ;
- gouvernement des numéraux ;
- flexion des anthroponymes/toponymes ;
- accord de coordination mixte ;
- agreement de `DetNP` sans tête ;
- standardisation des matériaux Geg pour numéraux/ordinaux.

## Tests canoniques

- toutes les cellules nombre × définitude × MorphCase du nom ;
- contraste syntaxique Dat/Gen ;
- ambigeneric sg/pl agreement ;
- nyje par Case/Gender/Number/Species ;
- adjectifs articulés/non articulés ;
- relative `cili` accordée ;
- possessifs ;
- quantifieurs, déterminants, numéraux et noms propres.
