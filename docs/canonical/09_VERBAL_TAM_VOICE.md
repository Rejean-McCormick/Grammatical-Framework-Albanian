# Verbal — TAM, auxiliaires, voix

## Invariants

- un seul realizer fini ;
- morphologie avant syntaxe ;
- morph-voice ≠ semantic voice use ;
- particules et clitiques occupent des slots structurés ;
- common RGL Tense garde son sens commun ;
- les séries albanaises supplémentaires restent dans l'extension/état interne.

## Décisions retenues

- Active perfect → `kam`; NonActive perfect → `jam` par défaut Standard, exceptions sourcées seulement.
- progressive = stratégie typée ; pas `po` concaténé librement.
- `Past` interne actuel est une dette de naming/semantics.
- aucune synthèse heuristique durable du non-actif depuis des strings actives.
- common `TPast + ASimul` cible l'imparfait ; l'aoriste est exposé comme distinction albanaise explicite.
- common `TPast + AAnter` cible le pluperfect à `kisha + participle`; autres séries restent marked/extension jusqu'à preuve.
- Standard/Tosk VV utilise par défaut des compléments finis/subjonctifs (`të`) plutôt qu'un pseudo-infinitif anglais.

## Questions encore ouvertes

- distribution complète progressive avec future/conditional/clitiques ;
- stratégie générique `PassV2` selon TAM ;
- reciprocal ;
- largeur productive des paradigmes non-actifs ;
- ordre particules/clitiques dans toutes les cellules ;
- surface publique optative/admirative ;
- surface publique Tosk non-finie (`për të ...`, `duke ...`) ;
- exceptions aux auxiliaires si une preuve lexicale future l'exige.

## Tests

Matrices TAM × anteriority × polarity × voice-use, plus participle/nonfinite, imperative, clitics et focused golds.
