# Preuve, variété et Gold

## Variety

Cible par défaut : `Standard Albanian`.

- Standard n'est pas « Tosk pur » ;
- Tosk est une source importante ;
- Geg reste étiqueté et ne devient Standard qu'avec corroboration ;
- campagnes dialectales futures ont namespaces/golds distincts.

## Faits linguistiques déjà bien établis dans les références fournies

- 5 cas grammaticaux : Nom, Acc, Dat, Gen, Ablat ; Dat/Gen morphologiquement identiques ;
- définitude nominale avec article postposé ;
- noms ambigénériques, dont le genre d'accord peut différer sg/pl ;
- Modern Albanian principalement Masc/Fem ; neutre résiduel/disputé ;
- adjectifs fléchis pour genre/nombre, avec classes articulées/non articulées ;
- *nyje* conditionnée par traits du référent/contexte ;
- relative `cili` fléchie et invariant `që` très courant ;
- système verbal avec présent, imparfait, aoriste, subjonctif, optatif, admiratif, participle, analytique/non-actif ;
- futur Standard/Tosk de type `do` + subjonctif, Geg distinct.

## Gold promotion

Un CASE devient `golded` seulement si : source-lock, variété, output exact, preuve, reviewer, rationale, decision reference et diff sont stockés. Un gold devient `stale` après changement d'une dépendance pertinente.

## Reviewer

Les rapports indiquent explicitement AI/human/dual. Ne jamais écrire « linguistically certified » sans qualifier le périmètre et le reviewer.
