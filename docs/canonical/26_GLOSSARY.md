# Glossaire global

**Common RGL** — surface abstraite partagée que chaque concrete language doit satisfaire.  
**English parity** — maturité/capacité comparable, pas imitation grammaticale.  
**Declared baseline** — état de coordination fourni par le mainteneur.  
**Evidence-backed run** — résultat effectivement archivé pour un source-lock.  
**MorphCase** — index de cellule morphologique nominale ; Gen peut mapper vers Dat.  
**Case** — rôle grammatical/syntaxique Nom/Acc/Dat/Gen/Ablat.  
**Ambigeneric** — nom dont le comportement de genre d'accord diffère selon le nombre.  
**Nyje** — particule/article de liaison conditionnée par le contexte nominal/adjectival.  
**MorphVoice** — forme active/non-active morphologique.  
**VoiceUse** — interprétation/usage actif, passif, réflexif, réciproque, etc.  
**CliticCluster** — structure typée des weak pronouns avant réalisation.  
**Lemgram** — identité morphologique/table, indépendante du sens/valence.  
**Placeholder** — réalisation compile-safe sans certification linguistique.  
**Golded** — output exact promu selon la policy de preuve/reviewer.  
**R4 candidate** — niveau global de parité/maturité, suffixé par reviewer level.

**S00–S11** — state machine normative du Compendium ; indique où le langage/subsystem peut légalement se situer.  
**W00–W08** — microcycle obligatoire d'un patch/workstream, de l'identification à la réconciliation.  
**R0–R4** — niveaux de maturité Albanian internes ; ne remplacent pas S00–S11.  
**RG-* requirement** — exigence du release gate Compendium.  
**Blocker overlay** — blocage explicite `BLOCKED_*` ou `DEFERRED_EXPLICITLY` attaché à un state.  
**Mandatory Task Header** — en-tête route/source/state exigé avant modification.
