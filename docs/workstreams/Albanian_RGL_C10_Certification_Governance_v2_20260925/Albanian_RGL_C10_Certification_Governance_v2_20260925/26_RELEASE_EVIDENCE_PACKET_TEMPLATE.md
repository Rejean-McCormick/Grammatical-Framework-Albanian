## Narratif obligatoire

Le `.md` associé explique :
1. ce qui est certifié;
2. ce qui n'est pas certifié;
3. ce qui a changé;
4. les bugs et dettes restants;
5. les preuves principales;
6. pourquoi le niveau annoncé est justifié.

Aucun packet ne se résume à un score global.
