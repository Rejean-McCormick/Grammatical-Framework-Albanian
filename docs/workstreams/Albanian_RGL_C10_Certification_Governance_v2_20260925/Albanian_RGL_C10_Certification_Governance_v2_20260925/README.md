# Albanian RGL — Conversation 10 Certification Governance v2

Ce paquet est la **source de cohérence locale** de la Conversation 10 : certification linguistique, golds, couverture, parité English et préparation des releases.

Commencer par [`00_START_HERE.md`](00_START_HERE.md).

## Architecture documentaire

La documentation est volontairement séparée en trois couches :

1. **Constitution / règles stables** — ce que signifient les termes, les preuves et les gates.
2. **Modèle de référence** — ce que la grammaire albanaise courante représente, quelles cellules/paradigmes existent, et ce qui doit être comparé à English.
3. **Évidence vivante** — CASEs, golds, couverture, bugs, dette et packets de release.

Cette séparation évite qu'un nouveau run ou une nouvelle hypothèse linguistique modifie silencieusement la définition de « valid », « gold », « parité » ou « terminé ».

Le document de plus haute autorité locale est `14_ANTI_DRIFT_CONSTITUTION.md`.
