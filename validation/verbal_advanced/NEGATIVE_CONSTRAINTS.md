# Verbal negative constraints

These combinations are deliberately not generated by the common realizer until Albanian evidence licenses them:

- progressive + future (`do të po ...`): `nonExist`;
- progressive + conditional (`do të po ...`): `nonExist`;
- progressive + anterior/perfect: `nonExist`;
- progressive + subjunctive (`të po ...`): `nonExist`;
- progressive + imperative: `nonExist`;
- progressive + analytic `PassiveUse`/weak `ReflexiveUse`: `nonExist` (pending evidence);
- common `TPast` never selects the aorist; explicit `AlbAoristS` owns that contrast.

The static validator checks these ownership rules in source.
